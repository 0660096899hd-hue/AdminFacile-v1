# AdminFacile V2.2.3 — Langue turque

Cette mise à jour ajoute le **turc** dans l’écran de traduction.

## Installation

Remplace uniquement :

```text
lib/main.dart
```

Puis exécute :

```powershell
flutter clean
flutter pub get
flutter analyze
flutter test
flutter run -d RFCW611W5BE
```

Le turc apparaît maintenant dans les langues source et cible. L’inversion Français ↔ Turc fonctionne également. Au premier usage, le modèle de langue peut être téléchargé automatiquement.
